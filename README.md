# Simple Banking System

A beginner-friendly Python project that simulates basic banking operations such as checking balance, depositing money, and withdrawing money.

## Features

* Customer name
* PIN creation and verification
* Check account balance
* Deposit money
* Withdraw money
* Insufficient balance checking
* Input validation
* Exit option

## Technologies Used

* Python 3.x

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in Command Prompt or Terminal.
3. Run the following command:

```bash
python banking_system.py
```

## How It Works

When the program starts, the user enters their name and creates a PIN.

The user can then:

1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

A PIN is required before performing banking operations.
